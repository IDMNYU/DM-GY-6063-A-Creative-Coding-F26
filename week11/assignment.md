## Data Visualization/Data Portraiture

Find a data source and write a sketch that visualizes that data in some capacity. The source can be anything with a public interface (ex. weather, transit, a stock exchange, a social platform, a government dataset, a sensor network, satellite imagery, a wiki's edit history, a database of species observations, etc etc etc) . The system you're visualizing may be public, commercial, governmental, or semi-private. This source may be static or dynamic.

As a question about the data and be specific! What are you trying to illustrate, hide(?), reveal, or argue for? Are you working with data that you need to refashion, or just taking what already exists?

- A tool like [https://jsonformatter.org/json-parser](https://jsonformatter.org/json-parser) will be useful identifying  information in an API and how to access it.
- Some sites to get you started with looking at datasets and APIs include
  - [NYC Open Data](https://www.nyc.gov/opendata)
  - [NY State Open Data](https://data.ny.gov)
  - [US Federal Data](https://data.gov)
  - [Public APIs](https://publicapis.lol/categories)
  - [Developer Oriented APIs](https://publicapis.dev)
  - [WikiPedia APIs](https://www.mediawiki.org/wiki/API:Action_API)
  - [Wordnik](https://developer.wordnik.com)
